# 隐私说明

## 数据在哪

**用户的金钱状态只存在用户自己的浏览器里(localStorage)。** 服务器不建账号、不落库、不持久化任何用户状态:

- 页面的日常操作(分配、记账、回看)由浏览器内执行的确定性函数完成,不发网络请求
- `/api/agent` 只在需要模型回应时被调用,请求即答即忘,服务端不存储对话
- MCP 会话缓存仅存在单实例内存中(随时可丢弃);主路径是客户端自己链回 `moneyState`,服务器不保管状态

设置页提供一键**导出 JSON** 与**清空数据**;清空即彻底删除,服务端无副本可言。

## 不收集什么

- 无账号体系:不要手机号、邮箱、真实姓名
- 不采集用户称呼;给小狗起的名字(可选)只存本地
- 无第三方统计、无广告 SDK、无追踪 cookie
- 浏览器侧无任何外部连接(CSP `connect-src 'self'` 强制)

## 模型调用的最小化

发给模型的内容只有当次任务需要的最小上下文:用户当轮输入、以及**已由代码格式化好的**状态摘要文本(如「3500 元」——不是完整状态对象)。模型 API Key 只存部署平台环境变量,不进代码仓库。

命中安全红线(自伤/借贷/投资等)的输入**不会发给模型**——输入闸直接返回固定安全回应;留存的审计事件只记风险类型与触发规则,**不含用户原文**。

## 给评审的验证方式

- 打开浏览器 DevTools → Network:日常操作零请求,只有主动对话时出现一次 `/api/agent`
- DevTools → Application → Local Storage:全部数据可见、可导出、可清除
- 响应头可见 CSP/nosniff/frame 拒绝等安全头(全站生效)
