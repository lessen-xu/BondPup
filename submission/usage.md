## 一、快速上手

体验 https://bondpup.vercel.app
评测 https://bondpup.vercel.app/?demo=1
MCP https://bondpup.vercel.app/mcp
健康检查 https://bondpup.vercel.app/health

带 ?demo=1 直接进示例数据主页，无需填问卷。

三分钟路径：
1. 主页可见四个罐子与小狗慢慢
2. 点「帮我看看要不要买」，输入物品与金额
3. 慢慢读安心罐余额、引用你以前的相似决定，给出三个完全对等的动作：现在买 / 放到明天 / 这次先不买
4. 选任一动作，确认后写入状态
5. 进「慢慢的小金库」，可见已确认的金钱原则卡

## 二、七步起点流程

访问 https://bondpup.vercel.app 从零开始，四罐数字全部从你自己的回答推出来，不套用 50/30/20，不引用平均房租之类的参考值。

1. 给小狗起个小名，默认「慢慢」，之后所有对话都用你起的名字
2. 这个月想怎么过：想攒下来一点 / 想让自己过得舒服一些 / 有个想买的东西 / 我想自己说说
3. 有没有想慢慢存钱的事，可跳过
4. 慢慢整理成几件「在意的事」，可改可删可加，你点头才写下来
5. 三个数字：能安排多少、必须花多少、有无已存。每项都有「我还不确定」，第二项可展开纯加法清单
6. 倒推目标月供，压力大时主动给出「把时间放长一点 / 先少存一点」两条路
7. 四罐生成，可改，确认后才写入

全程可跳过、可回改。

## 三、日常三个入口

【帮我看看要不要买】读安心罐余额 → 最多追问一句 → 三个中性动作 → 约定回看。

硬规则：可自由支配的钱只有安心罐，生活罐永不计入「可以买」。这条从根上避免了「生活罐还有 2300，所以 400 的衣服放得下」这类误判。

安心罐不够时只陈述差额并把选择权交回去：「按安心罐算会差 280 元。剩下这部分你想放在哪里？」绝不自动从别的罐子扣。

三个动作视觉完全一致，没有主按钮。「这次先不买」不会被表扬，到了约定的回看时间照样来问你「后来呢」。

【记一笔钱】先问金额，给候选罐建议，你确认后才改状态。

【有一笔钱想和你聊一聊】先接情绪，不追问用途，不给建议。最后两个选择：帮你记下来，或只是聊聊、不改余额。

## 四、四个罐子

生活罐：必须怎样活下去。安心罐：我愿意给自己多少自由。梦想罐：为哪件具体的事攒钱。未来罐：多少钱暂时不准备花。

恒等式：生活 + 安心 + 梦想月供 + 未来 = 本月可安排金额。余数进安心罐，未来罐默认 0 且永不自动接收——不预设「存钱=好」。

不强迫四罐都有钱，安心罐最大同样合法。界面上没有完成度、百分比、红色超支提示，也没有连续签到。

上期没花完的钱不挂在任何罐子名下，单独显示成一小堆碎钻，不催你处理，不庆祝不计数。

## 五、回看与金钱原则

每一种决定都可以约定回看，包括「这次先不买」。回看关注实际发生了什么，不统计你忍住了几次。

原则生成需要三条已完成回看的故事——必须有结果，不是三次决定。生成后是「候选」，附带证据可展开。你可以说「像我」「改说法」或「暂不确定」。只有确认或修改过，它才参与后续回应。冲突不覆盖，校验失败就不提。

示例：「我不是舍不得花钱，是要先看见它会不会进入生活。」

## 六、MCP 调用

Endpoint: https://bondpup.vercel.app/mcp　传输：Streamable HTTP，仅 POST

推荐调用顺序：
1. server/discover — 读取协议版本、capabilities 与 serverInfo
2. tools/list — 确认 5 个工具的描述与输入输出 schema
3. create_money_session — 创建匿名 demo 会话
4. plan_jars — 四罐分配，默认只预览，confirm:true 才写入
5. record_money_moment — 说一笔想花的钱，返回带签名的 proposal
6. confirm_action — 用户确认后写入
7. get_money_overview — 总览四罐、待回看、候选原则、结余历史

本地冒烟：node scripts/smoke-mcp.mjs https://bondpup.vercel.app

网页 API 与 MCP 调用同一套领域服务、同一个计算器、同一份安全规则，金额逻辑不复制。

## 七、源码验证

npm ci && npm run verify

一条命令串联 lint、typecheck、文案扫描、单元测试、生产构建、MCP 冒烟，无需任何环境变量即可运行。

## 八、边界

金额由确定性代码计算，改变罐子状态必须用户确认，跨罐永不自动级联。不做投资建议、银行连接、借贷产品。限定 18 岁以上，支持数据导出与一键清空。

## 九、复赛计划(仅随仓库,不进表单)

- 触发场景提取：不追问，直接从用户自然说出的话里提取触发场景（「同事临时约」→ 社交/临时），作为原则生成的额外证据——让原则不止来自行为，也来自动机
- 已确认原则的修改与删除接入网页 UI（后端与 MCP 已就绪）
- 证据筛选补 outcome 非空校验
