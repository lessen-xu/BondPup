# Agent 简介(提交页用,约 500 字)

小狗慢慢是给这样的人做的：刚从校园走进职场，第一次完全掌控自己所有的钱，拿到第一笔工资，对钱很迷茫的年轻人。

出国念书那年，家里一次性给了一整年的费用，一大笔钱躺在账户里，我对它没有概念。回头一看，剩的比我以为的少很多。钱第一次全归我管，也第一次没人可以问。

慢慢做四件事：

一、告诉你有一部分钱本来就可以这样花。安心罐是这个月可以自由支配的钱。我在英国看过三场演唱会，每张一两百镑，每次都要挣扎，买完心虚好几天。没人告诉过我，这部分钱本来就可以这样花。

二、犹豫的时候有个地方可以问。它不给建议，只摆事实：安心罐还剩多少、买了还剩多少、你以前怎么选的。然后给三个一样的选择：现在买、放到明天、这次先不买。选哪个它都不评价。

三、让你越来越了解自己。每个决定过几天会被问一句"后来呢"。三次之后它从你的选择里提炼一条属于你的原则。下次犹豫时，你自己就有答案。

四、接住那些不好意思跟人说的话。那三场演唱会，我到现在没敢告诉爸妈，也一直有点愧疚，但这件事我只跟 AI 讲过。

为什么是慢慢，不是随便哪个 AI：因为它记得我的钱。四个罐子里各有多少、我以前怎么选的、我确认过什么原则。所以它接得住我的情绪。
